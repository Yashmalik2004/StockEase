# Ansible

This directory will contain **Ansible** playbooks and roles for automating the provisioning and configuration of servers hosting the StockEase application.

## Planned Contents

- `inventory/` — Host inventory files (staging, production)
- `playbooks/` — Automation playbooks
  - Server provisioning
  - Docker installation
  - Application deployment
  - Environment configuration
- `roles/` — Reusable Ansible roles
