# Kubernetes

This directory will contain all **Kubernetes** manifest files for deploying and orchestrating the StockEase application in a cluster environment.

## Planned Contents

- Deployment manifests for frontend, backend, and MongoDB
- Service manifests (ClusterIP, NodePort / LoadBalancer)
- ConfigMaps and Secrets
- Persistent Volume and Persistent Volume Claims for MongoDB
- Ingress rules (if applicable)
- Namespace definitions
