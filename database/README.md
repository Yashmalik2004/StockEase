# Database

This directory will contain database-related configuration, schema definitions, seed data, and migration scripts for **StockEase**.

## Planned Technology

- **Database:** MongoDB (NoSQL Document Database)
- **ODM:** Mongoose
- **Hosting:** Local instance / MongoDB Atlas (TBD)

## Planned Collections

| Collection | Purpose |
|------------|---------|
| `users` | Admin user credentials and roles |
| `products` | Product catalogue and metadata |
| `stock` | Real-time stock quantity records |
